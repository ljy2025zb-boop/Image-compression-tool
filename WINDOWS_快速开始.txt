========================================
Windows 用户快速开始指南
========================================

欢迎 Windows 用户！

本项目可以在 Windows 上开发和运行，
也可以打包为 Windows .exe 可执行文件。

========================================
第一步：安装依赖
========================================

在命令提示符（CMD）或 PowerShell 中运行：

    pip install -r requirements.txt

========================================
第二步：运行应用
========================================

在命令提示符中运行：

    python main.py

========================================
第三步：使用应用
========================================

1. 点击"选择文件夹"按钮
2. 选择包含图片的文件夹（如 C:\Users\你的用户名\Pictures）
3. 点击"开始压缩"按钮
4. 等待处理完成

压缩后的图片会保存在：
原文件夹\compressed_png\ 目录中

========================================
打包为 Windows .exe（可选）
========================================

如果想打包为独立的 .exe 文件：

    build_windows.bat

打包完成后，dist\ImageCompressor.exe 就是可执行文件。

可以直接双击运行，无需安装 Python。

========================================
如何获取 macOS 的 .dmg 文件？
========================================

由于 .dmg 是 macOS 专有格式，有三种方法：

方法 1：使用 GitHub Actions（推荐，免费）
  1. 将代码上传到 GitHub
  2. GitHub 会自动在 macOS 环境打包
  3. 下载生成的 .dmg 文件

方法 2：借用 Mac 电脑
  1. 将项目文件夹复制到 Mac
  2. 在 Mac 上运行：./build_dmg.sh
  3. 获取生成的 .dmg 文件

方法 3：使用云端 macOS 服务（付费）
  - MacStadium
  - MacinCloud

详细说明请查看：WINDOWS_GUIDE.md

========================================
常见问题
========================================

Q: 提示缺少模块？
A: 运行 pip install -r requirements.txt

Q: 界面显示乱码？
A: 确保系统支持中文显示

Q: 可以在 Windows 上打包 macOS 应用吗？
A: 不可以，需要使用 GitHub Actions 或 Mac 电脑

Q: 打包的 .exe 文件太大？
A: 这是正常的，因为包含了 Python 和所有依赖库
