========================================
图片压缩工具 - 快速开始指南
========================================

欢迎使用图片压缩工具！

这是一个 macOS 原生应用，可以批量压缩图片并转换为 PNG 格式（≤ 500KB）。

========================================
第一步：安装依赖
========================================

在终端中运行：

    pip install -r requirements.txt

========================================
第二步：运行应用
========================================

在终端中运行：

    python main.py

========================================
第三步：使用应用
========================================

1. 点击"选择文件夹"按钮
2. 选择包含图片的文件夹
3. 点击"开始压缩"按钮
4. 等待处理完成

压缩后的图片会保存在：
原文件夹/compressed_png/ 目录中

========================================
可选：打包为 DMG（分发给其他人）
========================================

在终端中运行：

    chmod +x build_dmg.sh
    ./build_dmg.sh

打包完成后，dist/ImageCompressor.dmg 就是可分发的安装包。
